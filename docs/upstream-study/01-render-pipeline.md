# Firestorm render pipeline survey (branch `vkstorm-aleph`, checkout `C:\Dev\vkstorm-aleph-ref`)

Purpose: a pass-by-pass description of what Firestorm's OpenGL renderer does each frame, precise enough to rebuild it as a Vulkan frame graph with visually equivalent output. All paths are relative to `indra/`; line numbers are from this checkout. Setting defaults are from `newview/app_settings/settings.xml` (Firestorm's defaults, which differ from Linden's in places).

Conventions used below:
- "deferredScreen", "screen", "deferredLight", "shadow[i]" are members of `LLPipeline::RenderTargetPack` (`newview/pipeline.h:732-744`: `mMainRT`, `mAuxillaryRT` for reflection probes, `mHeroProbeRT` for mirrors). `gPipeline.mRT` points at whichever pack is current.
- Deferred rendering is always on: `RenderDeferred = true; // DEPRECATED` (`newview/pipeline.cpp:1213`). There is no forward-only path any more.
- HDR means `RenderHDREnabled && GL >= 4.05` (`newview/pipeline.cpp:912-913`, default on).
- "Legacy / Blinn-Phong" = pre-PBR materials (texture entry + optional `LLMaterial`); "PBR" = glTF materials (`LLGLTFMaterial`).

### 1.1 GPU pass list

Each entry: purpose; targets; inputs; shader(s); state; what is drawn; toggles.

#### Pass 1 -- Hero (mirror) probe faces (optional)
- Toggle: `RenderMirrors` (default **off**) and `RenderReflectionsEnabled`. `newview/llheroprobemanager.cpp:76-80, 242-247`.
- Per frame: `update()` picks the nearest visible box reflection-probe object flagged as mirror, computes the mirrored camera point `point = (reject - project) + hero_pos` and the clip plane through the mirror (`llheroprobemanager.cpp:135-218`). `renderProbes()` then renders `6/rate` faces per frame where `rate = RenderHeroProbeUpdateRate` clamped to {1,2,3,6} (default 2 => 3 faces/frame), face `i` when `gFrameCount % rate == i % rate` (`llheroprobemanager.cpp:265-294`).
- Each face: `gPipeline.mRT = &mHeroProbeRT` and `LLReflectionMap::update()` -> `LLViewerWindow::cubeSnapshot()` -> `display_cube_face()` (`llheroprobemanager.cpp:313-321`, `newview/llreflectionmap.cpp:53-75`, `newview/llviewerwindow.cpp:6644-6761`, `llviewerdisplay.cpp:1288-1398`). `display_cube_face` is a reduced `display()`: cull, `generateSunShadow` (only 2 splits in cube snapshots, `pipeline.cpp:11076`), `renderGeomDeferred`, `renderDeferredLighting`, no post. Camera: aspect 1, FOV 90 deg, near clip from the probe, user clip plane = mirror plane; avatars/particles only when the probe is "dynamic" (`llviewerwindow.cpp:6669-6705`).
- Targets: `mHeroProbeRT` pack allocated at `RenderHeroProbeResolution` (default 1024) square (`pipeline.cpp:931-937`); mirror scratch target `mRenderTarget` RGBA16F (RGBA8 if not HDR) with depth (`llheroprobemanager.cpp:107-112`); mip chain of `log2(res)` RGBA16F targets (`llheroprobemanager.cpp:114-123`).
- Post-processing of each face: 9-tap separable Gaussian (`gGaussianProgram`, weights at `app_settings/shaders/class1/interface/gaussianF.glsl:44`) horizontal into `mRenderTarget` then vertical back into `screen` (`llheroprobemanager.cpp:356-371`); then `gReflectionMipProgram` box-copies down the mip chain and `glCopyTexSubImage3D` into cube-array layer `(mReflectionProbeCount+1)*6+face` (`llheroprobemanager.cpp:373-412`).
- After all faces: `generateRadiance()` runs `gHeroRadianceGenProgram` (GGX importance-sampled prefilter, `class1/interface/radianceGenF.glsl:125-161`) for only `mipCount/4` mips into the hero probe's own layer (`llheroprobemanager.cpp:437-500`). The shader consumer therefore only trusts hero reflections for glossiness >= 0.75 (`class3/deferred/reflectionProbeF.glsl:722`).
- Cube array: `LLCubeMapArray::allocate(res, 3 comps, count+2, mips, hdr)` -> `GL_R11F_G11F_B10F` (HDR) or `GL_RGB8`, `(count+2)*6` layers, `LL_MAX_HERO_PROBE_COUNT` probes (`llrender/llcubemaparray.cpp:142-197`, `llheroprobemanager.cpp:570-600`).

#### Pass 2 -- Sun/moon cascaded shadow maps (4 splits)
- Toggle: `RenderShadowDetail > 0` (default 2). Entirely skipped for snapshots (`llviewerdisplay.cpp:934-939`) and when `mSunDiffuse` is black (`pipeline.cpp:11076-11079`).
- Function: `LLPipeline::generateSunShadow(camera)` `pipeline.cpp:10850-11633`.
- Targets: `mRT->shadow[0..3]`, depth-only (`allocate(w,h,0,true)`, color_fmt 0 => no color attachment), format `GL_DEPTH_COMPONENT24` (`llrender/llrendertarget.cpp:298-319`). Size: `BlurHappySize(screenW*RenderShadowResolutionScale)` x same for height, i.e. `(x*scale+16) & ~0xF` (`pipeline.cpp:1082, 1089-1104`). Default scale 1.0 => shadow maps are the screen resolution rounded to 16. Sampler state: anisotropic, clamp, `GL_COMPARE_R_TO_TEXTURE`/`GL_LEQUAL` (`pipeline.cpp:1140-1150`). Cube snapshots do not scale (`pipeline.cpp:1089`).
- Light direction: `caster_dir = sun up ? mSunDir : mMoonDir`; `lightDir = -caster_dir` (`pipeline.cpp:10960-10971`). Up vector = camera at-axis unless nearly parallel (>0.75) then camera up (`pipeline.cpp:10976-10984`).
- Split computation (`pipeline.cpp:10993-11062`): get the visible point cloud of the camera frustum clipped against scene extents (`getVisiblePointCloud`), transform to camera space, `near_clip = clamp(-max.z, 0.01, 4)`, `far_clip = clamp(-min.z*2, 16, 512)` then `min(far_clip, camera far)`. Split exponent `sxp = e.y + (e.x - e.y)*da^e.z` with `e = RenderShadowSplitExponent` (default `[3,3,2]`) and `da = 1 - max(|L.up|, |L.left|)`. `mSunClipPlanes[i] = near + range*((i+1)/4)^sxp`; then `mSunClipPlanes[0] *= 1.25`. In cube snapshots the splits are merged to 2 (`pipeline.cpp:11065-11070, 11082`). `RenderShadowSplits` (default 3) limits which split indices are rendered: `j > RenderShadowSplits` => that map is just cleared (`pipeline.cpp:11133-11156`).
- Per split `j` (`pipeline.cpp:11082-11450`): build an 8-corner sub-frustum from `dist[j]*0.75` to `dist[j+1]*1.25` with 5% lateral padding (`11115-11122`); gather the point cloud; light-space look matrix `look(camera.origin, lightDir, -up)`; least-squares best-fit line to choose a perspective "origin" so that the light projection is a *perspective* projection along the light's y axis (a variant of PSM) unless the error exceeds `RenderShadowErrorCutoff` (5.0) or the fitted FOV exceeds `RenderShadowFOVCutoff` (0.8 rad), in which case an **orthographic** projection over the point-cloud AABB is used (`11170-11400`). The resulting `proj[j]` is either `glm::ortho(min.x,max.x,min.y,max.y,-max.z,-min.z)` or the hand-built perspective matrix at `11396-11399`. `mSunShadowMatrix[j] = bias(0.5) * proj * view * inverse(camera view)` (`11431`), i.e. maps **camera-space** positions into shadow UV/depth.
- The near plane of each shadow camera is replaced by a universal plane `RenderFarClip*2` behind the camera along the caster direction (`10963-10968, 11415`), so casters far outside the view still cast.
- Render: `renderShadow(view, proj, shadow_cam, result, depth_clamp=true)` `pipeline.cpp:10417-10619`:
  - `sShadowRender=true`, occlusion disabled, `GL_CULL_FACE`, `GL_DEPTH_CLAMP`, depth `GL_LESS`; its own `updateCull`/`stateSort` against the shadow camera (with `LLOctreeCullShadow`).
  - Opaque: `gDeferredShadowProgram` (static then rigged variant), **color writes off** (`shadow_detail <= 2`, i.e. always; the VSM path is dead), draws `PASS_SIMPLE, FULLBRIGHT, SHINY, BUMP, FULLBRIGHT_SHINY, MATERIAL, MATERIAL_ALPHA_EMISSIVE, SPECMAP, SPECMAP_EMISSIVE, NORMMAP, NORMMAP_EMISSIVE, NORMSPEC, NORMSPEC_EMISSIVE` with no textures, then `PASS_GLTF_PBR` via `renderGLTFObjects` (`10485-10508`).
  - Occlusion queries for the shadow camera if `sUseOcclusion > 1` (`10511-10514`).
  - `renderGeomShadow`: pools with shadow passes -- terrain (`gDeferredShadowProgram`, `lldrawpoolterrain.cpp:169-199`), trees (`gDeferredTreeShadowProgram`, min alpha 0.5, polygon offset `RenderDeferredTreeShadowOffset/Bias`=1/1, `lldrawpooltree.cpp:113-140`), avatars (3 shadow passes opaque / alpha blend / alpha mask with `gDeferredAvatarShadowProgram`, `gDeferredAvatarAlphaShadowProgram`, `gDeferredAvatarAlphaMaskShadowProgram`; impostored, too-slow and invisible avatars cast no shadow, `lldrawpoolavatar.cpp:281-418`).
  - Alpha-tested casters (`10521-10603`): `gDeferredShadowAlphaMaskProgram` for `PASS_ALPHA_MASK`, `renderAlphaObjects` for `PASS_ALPHA` (alpha-blended faces are shadow-cast as a mask with cutoff `ALPHA_BLEND_CUTOFF = 0.598` `pipeline.cpp:249`, using `gDeferredShadowAlphaMaskProgram` or `gDeferredShadowGLTFAlphaBlendProgram`), `gDeferredShadowFullbrightAlphaMaskProgram` for `PASS_FULLBRIGHT_ALPHA_MASK`, `gDeferredTreeShadowProgram` with min alpha 0.598 for grass and `PASS_*_MASK` materials, `gDeferredShadowGLTFAlphaMaskProgram` for `PASS_GLTF_PBR_ALPHA_MASK` (+rigged). Uniforms: `sun_up_factor`, `target_width`.
- Settings also consumed by shadow sampling: `RenderShadowBias` (-0.002) + `RenderShadowBiasError*|cam.z|/3000` (-0.007), `RenderShadowOffset` (0.01), `RenderSpotShadowBias` (-0.0002), `RenderSpotShadowOffset` (0.04), `RenderShadowNoise`, `RenderDeferredSunWash` (0.5) (`pipeline.cpp:9341-9352`).

#### Pass 3 -- Spot (projector) shadow maps (2)
- Toggle: `RenderShadowDetail > 1` (default 2 => on). Skipped during cube snapshots (`pipeline.cpp:11458, 11574`).
- Targets: `mSpotShadow[0..1]`, depth-only `GL_DEPTH_COMPONENT24`, square `width = screenW*scale` (`pipeline.cpp:1113-1125`).
- Selection: the two highest-priority spotlights visible this frame (`mTargetShadowSpotLight[]`, priority from `LLVOVolume::updateSpotLightPriority`, chosen in `setupSpotLight` `pipeline.cpp:10155-10180`), with a fade in/out (`mSpotLightFade`) driven by camera velocity so swapping targets cross-fades (`11458-11495`).
- Camera: origin behind the light's near plane so the volume's XY scale at the near plane subtends `fov` (= spot params x), `near = dist+0.01`, `far = dist + radius*1.5`, aspect = scale.x/scale.y, `glm::perspective` (`11505-11555`). `mSunShadowMatrix[4+i]` likewise biased (`11566`). Rendered via `renderShadow(..., depth_clamp=false)` with `RenderSpotLight = drawable` so the projector's own geometry is skipped (`stateSort` `pipeline.cpp:3456`).

#### Pass 4 -- Avatar impostors
- `LLVOAvatar::updateImpostors()` `newview/llvoavatar.cpp:12240-12258` regenerates each visible avatar that `isImpostor()` (visibility rank > `RenderAvatarMaxNonImpostors`=12, or jelly-dolled) and `needsImpostorUpdate()` (angle/distance change thresholds `llvoavatar.cpp:3558-3596`).
- `LLPipeline::generateImpostor()` `pipeline.cpp:11735-12120`: camera looks at the avatar, FOV fitted to its extents, perspective near 1 far 256 (`11925-11948`); resolution = next pow2 of pixels covered, max 512x512 each (`11954-11957`); target `avatar->mImpostor` RGBA8 + depth **plus the full deferred attachment set** (`addDeferredAttachments(avatar->mImpostor, true)` `11963-11968`), so an impostor is a mini G-buffer (diffuse, ORM/spec, normal, [emissive]).
- Draws `renderGeomDeferred` + `renderGeomPostDeferred` with `sImpostorRender=true, sShadowRender=true, sReflectionRender=!deferred` (`11807-11811, 11995-12012`), then a second depth-only post-deferred pass (`sImpostorRenderAlphaDepthPass`) to put alpha geometry into depth, then a full-screen quad at depth 0.99999 with `GL_GREATER` writes alpha=1 (or the muted color) wherever nothing was drawn, producing the alpha cutout (`12020-12070`).
- Consumption: `LLDrawPoolAvatar` deferred pass 0 (`beginDeferredImpostor`, `gDeferredImpostorProgram`, min alpha 0.01) binds impostor textures 0/1/2 to diffuse/specular/normal and draws a camera-facing quad (`lldrawpoolavatar.cpp:551-566, 884-896`, `llvoavatar.cpp:6387-6450`). Impostored avatars draw nothing else (`lldrawpoolavatar.cpp:845-851`).

#### Pass 5 -- G-buffer fill: `renderGeomDeferred`
- Function `pipeline.cpp:4220-4356`. Target `mRT->deferredScreen` (layout in section 2), viewport = screen res (after `RenderResolutionDivisor`/`RenderResolutionMultiplier`, `pipeline.cpp:946-967`). Color mask `(true,true)` inside (`4280`); `GL_CULL_FACE` on (`4256`); depth test/write on `GL_LEQUAL` from `display()`.
- Prologue: computes `gGLDeltaModelView` = last-frame camera space -> this-frame camera space (for SSR reprojection) (`4234-4246`); `setupHWLights()` (section 3); `prerender()` on every pool; `mReflectionMapManager.updateUniforms()` + `mHeroProbeManager.updateUniforms()` (fills and uploads the probe UBO) (`4271-4275`).
- Pool iteration in `LLDrawPool` type order (`newview/lldrawpool.h:57-79`): `POOL_SKY, WATEREXCLUSION, WL_SKY, SIMPLE, FULLBRIGHT, BUMP, MATERIALS, GLTF_PBR, TERRAIN, GRASS, GLTF_PBR_ALPHA_MASK, TREE, ALPHA_MASK, FULLBRIGHT_ALPHA_MASK, AVATAR, CONTROL_AV, GLOW, ALPHA_PRE_WATER, VOIDWATER, WATER, ALPHA_POST_WATER`. Only pools with `getNumDeferredPasses() > 0` draw here. **Occlusion queries** (`doOcclusion`) are issued just before the first pool of type >= `POOL_GRASS` (`4290-4296`), i.e. after all fully-opaque geometry.
- Deferred-pass pools (what is drawn, shader, notes):
  - **WL sky** (`POOL_WL_SKY`): `lldrawpoolwlsky.cpp:471-500`. Dome with `gDeferredWLSkyProgram` (`skyV/skyF`), `LLGLSPipelineDepthTestSkyBox(true,true)` = cull off, depth test+write on, projection squashed to z=0.99999 (`llrender/llgl.cpp:2919-2933, 3003-3008`); then sun and moon quads (`gDeferredWLSunProgram`, `gDeferredWLMoonProgram`, blend alpha, depth write on so the moon clips stars `lldrawpoolwlsky.cpp:354-469`); then stars (`gDeferredStarProgram`, additive-with-alpha blend, no depth write, skipped in cube snapshots `219-288`); then clouds (`gDeferredWLCloudProgram`, alpha blend, depth test+write, skipped in irradiance passes `290-352, 495-498`). After the pass, **`glClear(GL_DEPTH_BUFFER_BIT)`** (`endDeferredPass` `lldrawpoolwlsky.cpp:84-93`), so the sky never occludes. Sky writes `GBUFFER_FLAG_SKIP_ATMOS` (section 2).
  - **Simple** (`POOL_SIMPLE`): `gDeferredDiffuseProgram` static + rigged, `PASS_SIMPLE(_RIGGED)`, blend off, texture batching on (`lldrawpoolsimple.cpp:94-114`). Shader `diffuseF.glsl` writes diffuse rgb, spec = vertex alpha replicated, normal with env = vertex alpha and `GBUFFER_FLAG_HAS_ATMOS` (`class1/deferred/diffuseF.glsl:40-52`).
  - **Bump** (`POOL_BUMP`): `gDeferredBumpProgram`, `PASS_BUMP(_RIGGED)` with per-batch `setMinimumAlpha(mAlphaMaskCutoff)` and a bump map bound per draw (`lldrawpoolbump.cpp:539-596`); `bumpF.glsl` discards below cutoff and perturbs the normal (`class1/deferred/bumpF.glsl:45-72`).
  - **Materials** (`POOL_MATERIALS`): 12 passes x {static, rigged} = 24 deferred passes, one `gDeferredMaterialProgram[idx]` per combination of {none, specmap, normmap, normspec} x {opaque, mask, emissive}; the *blend* variants are not drawn here (`lldrawpoolmaterials.cpp:47-170`). Uniforms per batch: `specular_color`, `env_intensity`, `emissive_brightness`, `minimum_alpha`, diffuse/spec/normal textures.
  - **GLTF PBR** (`POOL_GLTF_PBR`, `POOL_GLTF_PBR_ALPHA_MASK`): `gDeferredPBROpaqueProgram` (+rigged) over `PASS_GLTF_PBR(_RIGGED)` / `PASS_GLTF_PBR_ALPHA_MASK(_RIGGED)`; also `LL::GLTFSceneManager` (local glTF scenes) (`lldrawpoolpbropaque.cpp:48-69`). `pbropaqueF.glsl` writes linear basecolor, ORM, normal with flag `HAS_PBR`, emissive (`class1/deferred/pbropaqueF.glsl:68-122`).
  - **Terrain**: `gDeferredTerrainProgram` (texture terrain) or `gDeferredPBRTerrainProgram[paint_type]` (`lldrawpoolterrain.cpp:145-242, 351+`).
  - **Grass** (`POOL_GRASS`): `gDeferredNonIndexedDiffuseAlphaMaskProgram`, min alpha 0.5 (`lldrawpoolsimple.cpp:137-152`).
  - **Tree** (`POOL_TREE`): `gDeferredTreeProgram`, min alpha 0.5, each tree face as one draw (`lldrawpooltree.cpp:56-110`).
  - **Alpha mask** (`POOL_ALPHA_MASK`): `gDeferredDiffuseAlphaMaskProgram` over `PASS_ALPHA_MASK(_RIGGED)` via `pushMaskBatches` (sets `minimum_alpha` per batch) (`lldrawpoolsimple.cpp:116-135`).
  - **Avatar** (`POOL_AVATAR`, `POOL_CONTROL_AV`): 3 deferred passes: impostor quad (pass 0), rigid parts/eyeballs (`gDeferredNonIndexedDiffuseAlphaMaskNoColorProgram`, pass 1), skinned body (`gDeferredAvatarProgram`, pass 2) with `sSkipTransparent=true` (`lldrawpoolavatar.cpp:172-229, 551-672`). Rigged mesh attachments are *not* drawn here; they live in the `_RIGGED` passes of the other pools with a per-batch matrix palette upload (`lldrawpool.cpp:685-777`).
  - Pools with **no** deferred pass (drawn later, forward): `POOL_SKY`(legacy, unused), `POOL_FULLBRIGHT`, `POOL_FULLBRIGHT_ALPHA_MASK`, `POOL_GLOW`, `POOL_ALPHA_*`, `POOL_WATER`, `POOL_VOIDWATER`, `POOL_WATEREXCLUSION`.
- Ends with color mask `(true,false)`.

#### Pass 6 -- Sun/shadow/SSAO "light map": `gDeferredSunProgram`
- `pipeline.cpp:9455-9483`. Condition: `(RenderDeferredSSAO && !gCubeSnapshot) || RenderShadowDetail > 0`.
- Target `mRT->deferredLight` (RGBA16F if HDR else RGBA8, screen res; allocated when hdr || shadows || ssao || DoF `pipeline.cpp:986-996`), cleared to `(1,1,1,1)`. Full-screen triangle (`mScreenTriangleVB`), blend off, depth test off (`GL_ALWAYS`, no write).
- Shader: `class2/deferred/sunLightSSAOF.glsl` when SSAO on, `sunLightF.glsl` otherwise (`llviewershadermgr.cpp:1733-1745`); cube snapshots use `gDeferredSunProbeProgram` (no SSAO). Output: `.r` = directional shadow factor, `.g` = AO (1.0 when SSAO off), `.b/.a` = spot shadow 0/1 (`sunLightSSAOF.glsl:41-54`).
- Shadow sampling (`class1/deferred/shadowUtil.glsl:96-195`): position offset along the light by `shadow_offset*2*(1-N.L)`; cascade chosen by camera-space z against `shadow_clip*-0.75` (near) and `*-1.25` (far), with linear cross-fade in the overlap; each cascade is a 5-tap PCF (`pcfShadow` 54-71: centre weighted 4, four diagonal taps, result *0.125) on `sampler2DShadow` with depth bias `shadow_bias*2` and an x-jitter trick; beyond `shadow_clip.w` returns 1. Spot shadows: 5-tap PCF with `proj_shadow_res` offsets (`73-94, 197-241`).
- SSAO (`class1/deferred/aoUtil.glsl:77-117`): 8 fixed kernel taps scaled by `min(ssao_radius/-z, ssao_max_radius)` and reflected by a 128x128 noise texture; `ssao_factor` 0.30, radius 500, max 200 (defaults), all divided by the screen/target height ratio (`pipeline.cpp:9321-9330`).
- Inputs: G-buffer depth and normal (bound by `bindDeferredShader`), 4+2 shadow maps, `mNoiseMap`.

#### Pass 7 -- SSAO soften blur (two passes)
- Only when `RenderDeferredSSAO && !gCubeSnapshot` (`pipeline.cpp:9485-9546`). `gDeferredBlurLightProgram` (`blurLightF.glsl`), separable 4-sample Gaussian with weights from `RenderShadowGaussian` (default `[3,2,0]`), `kern_scale = RenderShadowBlurSize*(1.5)` (1.4), `dist_factor = RenderShadowBlurDistFactor` (0). Horizontal pass writes `mRT->screen` (used as scratch, cleared to white), vertical pass writes back to `deferredLight`. Blend off, depth off.

#### Pass 8 -- Clear `screen` and "soften" (sun + ambient + IBL + emissive): `gDeferredSoftenProgram`
- `pipeline.cpp:9548-9584`. Target `mRT->screen` (RGBA16F, shares depth with deferredScreen `pipeline.cpp:982-984`), cleared to `(0,0,0,0)` -- alpha is the glow accumulator and must start at 0. Full-screen triangle, blend off, depth off. Toggle `RenderDeferredAtmospheric` (default on; off => the screen stays black and only local lights/forward geometry appear).
- Shader `class3/deferred/softenLightF.glsl` (HAS_SUN_SHADOW / HAS_SSAO permutations `llviewershadermgr.cpp:2149-2160`). Per pixel (`softenLightF.glsl:119-285`):
  1. Reconstruct view-space position from depth (`getPositionWithDepth`), read G-buffer.
  2. `scol = max(lightMap.r, albedo.a)` (albedo alpha = emissive/fullbright flag for legacy materials), `ambocc = lightMap.g`.
  3. `calcAtmosphericVarsLinear()` (section 3.4) gives `sunlit, amblit, additive, atten`.
  4. **PBR branch** (`GBUFFER_FLAG_HAS_PBR`): `orm = spec.rgb` (occlusion, roughness, metallic); `sampleReflectionProbes(irradiance, radiance, ...)`; `adjustIrradiance` mixes SSAO darkening (`ssao_irradiance_scale`=0.6, `ssao_irradiance_max`=0.18); `calcDiffuseSpecular` (F0 0.04); `pbrBaseLight()` (`deferredUtil.glsl:573-622`): IBL via split-sum BRDF LUT + punctual sun `clamp(nl*(diff+spec),0,10) * sunlit * 3.0 * scol` (non-classic) + `iblSpec` + emissive.
  5. **HDRI sky** flag: copy emissive.
  6. **SKIP_ATMOS** (sky/clouds/sun/moon/stars): `color = srgb_to_linear(baseColor or emissive) * sky_hdr_scale`.
  7. **Legacy branch**: albedo and spec converted sRGB->linear; `sampleReflectionProbesLegacy` (irradiance, glossenv at `(1-gloss)*maxLod`, legacyenv at lod 0 when env > 0); `color = irradiance + min(N.L, scol)*sunlit` (or classic-mode gamma-space mix) times albedo; Blinn-Phong sun specular using the `lightFunc` LUT; `applyGlossEnv` (`reflectionProbeF.glsl:893-902`, halved, fresnel-weighted, "fake energy conservation"); `mix(color, albedo, albedo.a)` (fullbright/emissive restore); `applyLegacyEnv` (`904-913`, legacy shiny reflection mixed by env intensity).
  8. `frag_color = clampHDRRange(color * (classic ? 1.1 : 1))`, alpha 0 (`clampHDRRange` clamps to [0, 11.2] and kills NaN/inf, `deferredUtil.glsl:83-93`).
- Uniforms set here besides `bindDeferredShader`: `sun_up_factor`, `lightnorm` (clamped light norm), `waterPlane`.

## 3. Lighting model

### 3.1 Sun / moon
- `setupHWLights()` `pipeline.cpp:6357-6587`: `mSunDir`, `mMoonDir` from `LLEnvironment::getSunDirection/getMoonDirection` (`llenvironment.cpp:1678-1696`; sky's `mSunDirection = x_axis * sun_rotation` `llsettingssky.cpp:1336-1351`). `mSunDiffuse = psky->getSunlightColor()` **normalised so max component <= 1 and clamped** (`6397-6408`); moon the same (moon colour = sun colour, `llsettingssky.cpp:1684-1687`). If neither sun nor moon is up: both black, direction `(0,1,0)` (`6412-6418`). Light 0 = sun or moon by `getIsSunUp()` (sun z >= 0, `llsettingssky.cpp:1324-1334`).
- Uniforms: `sun_dir`/`moon_dir` are the *view-space* transformed directions `mTransformedSunDir/MoonDir` (`pipeline.cpp:9445-9452, 9354-9355`); `sunlight_color`/`moonlight_color` = `mSunDiffuse`/`mMoonDiffuse` (`9375-9383`, optionally scaled by `RenderSkyAutoAdjustSunColorScale`); `lightnorm` = clamped light norm (z clamped to >= -0.1, `llenvironment.cpp:1719-1727`) in **world** space, used by atmospherics.
- In shaders the sun term is `min(N.L, shadow) * sunlit` (legacy) or `pbrPunctual * sunlit * 3.0 * scol` (PBR), where `sunlit` is `sunlight_color` attenuated by the atmosphere (`calcAtmosphericVars`) and scaled by `sky_sunlight_scale` (`RenderSkySunlightScale` / `RenderHDRSkySunlightScale`, both 1.0 in Firestorm), then (non-classic) converted sRGB->linear (`atmosphericsFuncs.glsl:147-165`). `classic_mode` (legacy sky without probe ambiance, `llsettingsvo.cpp:810`): `sunlit *= 1.35`, N.L^1.2, gamma-space mixing and final 1.1 scale (`softenLightF.glsl:159-160, 226-233, 279-283`).
- Avatar backlight light 1 (`setupAvatarLights` `6054-6135`) is only used by forward avatar preview paths.

### 3.2 Local (point/spot) lights
- Candidate set `mNearbyLights` (`calcNearbyLights` `6169-6355`): all `LLDrawable::LIGHT` drawables within `RenderFarClip` (deferred), sorted by `calc_light_dist` (distance minus radius, moving lights 25% closer, selected lights first); fade in/out over `LIGHT_FADE_TIME`; attached lights skipped when `RenderAttachedLights` off; lights on muted/too-complex avatars dropped; HUD lights ignored. Not recomputed for reflection renders, cube snapshots, HUDs.
- **Deferred path** (pass 9): up to `RenderLocalLightCount` (256) lights, each either a cube volume (camera outside) or a full-screen batch. Radius `s = getLightRadius()*1.5`; falloff `getLightFalloff(DEFERRED_LIGHT_FALLOFF=0.5)`; attenuation `dist = d/s; a = (1 - clamp((dist+falloff)/(1+falloff)))^2 * 2` (`deferredUtil.glsl:95-103`). Spot: cone from `getSpotLightParams()` (fov, focus, ambiance), projector texture with LOD by distance beyond focus, edge fade, plus a diffuse "ambiance" term (`deferredUtil.glsl:220-260`, `spotLightF.glsl:146-267`). Two spotlights get shadow maps (`proj_shadow_idx`, from `lightMap.b/.a`).
- **Forward path** (alpha, materials-blend, PBR-blend, water): the first 6 nearby lights go into "hardware" light slots 2-7 (`setupHWLights` `6442-6572`): position (agent space), diffuse (linear, faded), `linatten = 3*(1+2*falloff)/adjusted_radius`, quadratic = `falloff+1`, `size = r*1.5`, spot direction/cutoff 90/exponent 2 or omni flag `specular.z = 1`. `LLLightState` feeds `light_position/direction/attenuation/diffuse[8]` uniforms; forward shaders loop `LIGHT_LOOP(1..7)` with `calcPointLightOrSpotLight` (`alphaF.glsl:84-169`). The deferred shader `pointLightF.glsl` and the forward helper are tuned to match but are **not** identical (forward has no specular in `alphaF`, has it in `materialF`).
- Legacy light colour -> linear: `LLVOVolume::getLightLinearColor()` (sRGB->linear of the prim light colour times intensity).

### 3.3 Ambient / IBL
- `ambient_color` uniform = `psky->getTotalAmbient()` = the sky's ambient setting (`llsettingssky.cpp:1759, 1678`), zeroed during irradiance probe passes, scaled by `RenderSkyAutoAdjustAmbientScale` for auto-adjusted legacy skies (`llsettingsvo.cpp:825-861`). In the shader `amblit = pow(ambient + (1-ambient)*cloud_shadow*0.5, 0.9) * 0.57`, then `* ambientLighting(norm, L)` (a 0.75..1 "wrap"), then (non-classic) sRGB->linear and **desaturated to luma** (`atmosphericsFuncs.glsl:110-125, 137-165`), times `sky_ambient_scale`.
- Irradiance actually used = `sampleProbeAmbient()` = weighted blend of 16x16 irradiance probes, each `mix(amblit, probeSample*refParams.x, min(refParams.x,1))` where `refParams.x = max(sky probe ambiance, probe ambiance) * fade` (`reflectionProbeF.glsl:542-574, 634-691`; `llreflectionmapmanager.cpp:1220-1224`). Radiance = `sampleProbes()` at `lod = (1-gloss)*max_probe_lod`, parallax-corrected for manual box/sphere probes (`501-534, 576-632`). SSAO multiplies irradiance (`adjustIrradiance`).
- Legacy "shiny" env reflections also come from the probes (`legacyenv`, lod 0) and the old sky cubemap is only bound when probes are disabled (`pipeline.cpp:9284-9303`, `llvosky.cpp:707-709`).

### 3.4 Atmospherics (haze)
- CPU: `LLSettingsVOSky::applyToUniforms/applySpecial` (`llsettingsvo.cpp:725-869`) push per-frame uniforms: `ambient_color, blue_density, blue_horizon, haze_density, haze_horizon, density_multiplier, distance_multiplier, cloud_pos_density1/2 (+scroll), cloud_scale, cloud_shadow, cloud_variance, glow, max_y, moon_brightness, moisture_level, droplet_radius, ice_level, reflection_probe_ambiance, lightnorm, camPosLocal, sunlight_color, moonlight_color, cloud_color, scene_light_strength (= 2*(0.75+sdr*sun.z), 658-680), sky_sunlight_scale, sky_ambient_scale, classic_mode, sky_hdr_scale (= sqrt(gamma)*2 for EEP skies, auto-adjust scale, or 1), gamma, sun_up_factor, sun_moon_glow_factor`. `draw_color` desaturates blue horizon/density to luma during irradiance passes when `RenderDesaturateIrradiance` (`688-722`). `LLEnvironment::updateShaderUniforms` applies the `SG_ANY` group plus the shader's group (default/sky/water) when a shader is bound (`llenvironment.cpp:1840-1851`).
- GPU: `calcAtmosphericVars` (`class1/windlight/atmosphericsFuncs.glsl:51-131`) per pixel: `rel_pos` clamped to `max_y`; `light_atten = (blue_density + haze_density*0.25)*density_multiplier*max_y`; sunlight attenuated by `exp(-light_atten / lightnorm.y)`; `combined_haze = exp(-(blue_density+haze_density)*|rel_pos|*density_multiplier*distance_multiplier)` => `atten`; haze glow from `glow.x`, `glow.z` and `sun_moon_glow_factor`; `additive = (blue_horizon*blue_weight)*(cs+tmpAmbient) + (haze_horizon*haze_weight)*(cs*haze_glow + tmpAmbient)`, `* (1-combined_haze)`, clamped to 10; `sunlit = sunlight`. Applied as `light*atten.r + srgb_to_linear(additive*2)*sky_hdr_scale` (`atmosphericsF.glsl:35-42`) either in-shader (forward) or by the haze full-screen pass (deferred).
- Sky dome vertex shader (`class1/deferred/skyV.glsl:70-166`) uses a parallel but **different** formula (long-ray variant, `off_axis = 1/(max(0,rel.y)+lightnorm.y)`, below-cloud blend). `skyF.glsl` adds rainbow/halo and multiplies by 2 and clamps to 5 (`84-128`). The CPU twin is `LLSettingsSky::calculateLightSettings` (`llsettingssky.cpp:1707-1760`) producing `mSunDiffuse/mSunAmbient/mHazeColor` (used for legacy fog/water colour).

### 3.5 Shadows: see passes 2-3 and 6. Summary: 4 sun cascades (3 rendered by default), 2 spot maps, all depth24 at ~screen res, 5-tap PCF with cascade cross-fade, `RenderShadowDetail` 0/1/2.

### 3.6 SSAO: pass 6-7 (8 taps, 2-pass blur, darkens irradiance only).

### 3.7 SSR: `RenderScreenSpaceReflections` default off; when on, `reflectionProbeF.glsl:752-768, 867-885` mixes SSR hits (traced against last frame's `mSceneMap`) into `glossenv`/`legacyenv` for glossiness >= 0.9 (PBR) or always (legacy).

### 3.8 PBR vs legacy side by side
Both share the G-buffer; the flag in `normalMap.w` selects the branch in every lighting shader (`softenLightF.glsl:167-276`, `pointLightF.glsl:95-152`, `spotLightF.glsl:146-267`, `multiPointLightF.glsl:88-172`). Legacy data is stored **sRGB** and linearised at lighting time; PBR data is linear. Legacy specular = Blinn-Phong via `lightFunc` LUT with `fres = (1-V.H)^5*0.4+0.5` and a Kelemen-style `gt` term; PBR = Cook-Torrance GGX (`deferredUtil.glsl:427-517`) with min roughness 8/255 and `reflectance90 = clamp(reflectance*25)`.

Probes sorted by distance; slots freed for probes beyond `mReflectionProbeCount`. Occluded probes (GPU occlusion query on their sphere, `doOcclusion` `1650-1661`, `llreflectionmap.cpp:346+`) are only "touched". A 2-second fade (`mResetFade`) after reallocation.

## 5. Post chain -- see passes 12-22. Compact view of the data flow (HDR, defaults):

`screen(RGBA16F linear, a=glow)` -> [SSR copy -> mSceneMap] -> luminance(256^2) -> exposure(1x1, temporal) -> tonemap(ACES Hill, mix 0.7 / 0 for legacy sky) + sRGB encode (+legacy `1-(1-c)^gamma`) -> CAS(0.4) -> `ping(RGBA8 sRGB)` -> glow extract(alpha only, 512x512) -> 4 blur passes -> combine (add) -> `pong` -> [DoF] -> [FXAA|SMAA] -> [vignette/frame] -> present + noise + depth write -> HUD/UI on the backbuffer.

Everything from glow onwards happens on **8-bit sRGB-encoded** data; glow is extracted after tonemapping. `RenderExposure` is applied in the shader, not in the exposure buffer. Legacy skies: no tonemap curve (mix 0), exposure range [1,1], legacy gamma curve with the sky's `gamma` setting.

## 6. Water and sky

### Sky
- Geometry: `LLVOWLSky` dome of `WLSkyDetail` (64, clamp 8-180) stacks x `2*detail` slices at `dome_radius` (EEP `DOME_RADIUS` 15000, `llsettingssky.cpp:150`), stack angle `phi = pi/8 * biased(t)` (`llvowlsky.cpp:101-118, 380-440`), as triangle strips in `RenderMaxVBOSize`-limited segments; drawn translated to the camera, rotated 120 deg about (1,1,1)/sqrt3, scaled 1/3, offset by `-camHeightLocal` (`lldrawpoolwlsky.cpp:95-128`). Stars: random points on the upper hemisphere at dome radius, drawn as quads rotating 0.01 deg/s (`llvowlsky.cpp:286-294, 338-378`, `lldrawpoolwlsky.cpp:265-280`). Sun/moon: camera-centred quads at `HEAVENLY_BODY_DIST = HORIZON_DIST-20` scaled by disk radius 0.5/0.45 and the EEP sun/moon scale (`llvosky.h:41-44`, `llvosky.cpp:1105-1145`), with two-texture blending across day-cycle keyframes. Clouds: dome again with `gDeferredWLCloudProgram` (`cloudsF.glsl:59-127`: two noise textures blended, density/variance, alpha squared twice, self-shadow). HDRI sky (debug, `gEXRImage`) replaces the dome when loaded.
- Writes G-buffer with `SKIP_ATMOS` so the soften pass just linearises and scales by `sky_hdr_scale`; the haze pass discards depth==1.
- The legacy `LLVOSky` cubemap (`llvosky.cpp:536-803`) is generated only when probes are disabled.

### Water
- Geometry: `LLVOWater` 16x16 subdivided patches per region (`llvowater.h:35`, `llvowater.cpp:111-245`) plus "edge patches" (`LLVOVoidWater`) out to the horizon; vertex shader pushes far vertices for a horizon effect and computes 3 wave UV sets (`class1/environment/waterV.glsl:56-109`).
- Passes: (a) occlusion queries use depth clamp for water (`llvieweroctree.cpp:1217-1222`); (b) exclusion mask (pass 10a); (c) water haze (10b); (d) refraction copy of `screen`+depth into `mWaterDis` (`lldrawpoolwater.cpp:111-140`); (e) water surface `class3/environment/waterF.glsl` (`183-348`): three normal-map taps blended across two normal textures by `blend_factor`, fresnel from `fresnelScale/Offset`, refraction = `screenTex` sampled at the distorted screen coordinate with depth-based rejection and shoreline fade (`SHORELINE_FADE` off => `fade = water_mask`), reflection from **probes only** (`sampleReflectionProbesWater`: manual probes + default probe, no automatic ones) at `gloss = 1 - blurMultiplier*2`, sun specular via `pbrPunctual` (metallic 1, roughness = blur), `color = mix(refraction, radiance*df2.y, df2.x) + punctual`, alpha = water mask spec. ## 7. Culling, visibility, LOD, batching, vertex formats

- Spatial structure: per region, `LLViewerRegion::NUM_PARTITIONS` `LLSpatialPartition`s (one per drawable type: volume, bridge, terrain, water, tree, particle, hud...), each an octree of `LLSpatialGroup`s; attachments and animated linksets are `LLSpatialBridge`s (sub-octrees with their own transform). `updateCull` (`pipeline.cpp:2637-2721`) traverses each partition with `LLOctreeCull` (`llspatialpartition.cpp:1054-1114`): frustum test against group bounds (`AABBInFrustumNoFarClip` + sphere), `earlyFail` rejects groups marked `OCCLUDED`, `processGroup` -> `markNotCulled` pushes the group to `sCull` (visible groups or per-drawable groups) and marks it for an occlusion query if it `needsUpdate()` or was not visible last frame. Shadow cameras use `LLOctreeCullShadow`; `RenderUseFarClip` off uses no-far-clip variant.
- Occlusion queries (`sUseOcclusion == 2` when `UseOcclusion`): `doOcclusion` (`pipeline.cpp:2781-2872`) binds `gOcclusionCubeProgram`, depth test on / write off, colour off, draws each query group's bounding box (3 visible faces, `box_center/box_size` uniforms, fudge `SG_OCCLUSION_FUDGE`) inside `GL_ANY_SAMPLES_PASSED` (`llvieweroctree.cpp:1174-1260`); results read next frame(s) in `checkOcclusion` with `RenderOcclusionTimeout` (8) frames max latency (`1107-1172`). Issued once per frame after opaque pools in the G-buffer pass, plus for the shadow cameras, plus reflection-probe spheres. Queries are per camera (`mOcclusionQuery[NUM_CAMERAS]`).
- `stateSort` (`pipeline.cpp:3288-3414`): resets face pools, for drawable groups marks drawables visible and calls `rebuildMesh`; for visible groups with `changeLOD()` (distance moved by more than `mSlopRatio` of radius, or dirty) re-runs `stateSort(drawable)` -> `updateDistance` -> `LLVOVolume::updateLOD`; then `postSort`.
- LOD (`llvovolume.cpp:1608-1621, 1664-1834`): `distance = mDistanceWRTCamera * sDistanceFactor`, close-range ramp below `2*RenderVolumeLODFactor`, `* pi/3`; `lod_factor = RenderVolumeLODFactor (2.0) * (defaultFOV/currentFOV)`; `tan_angle = lod_factor*radius/distance` -> `LLVolumeLODGroup::getDetailFromTan` -> LOD 0..3. Rigged meshes use the avatar's distance and animated-extents radius. Group distance `calcDistance` (`llspatialpartition.cpp:644-721`) adds the alpha-sort depth (`mDepth` to the box front) and squashes distances < 16 m.
- Draw list construction (`postSort` `3750-3922`): for each visible group not occluded/auto-hidden, every `LLDrawInfo` in `group->mDrawMap[pass]` is appended to `sCull`'s per-pass list (`pushDrawInfo`), alpha groups to a separate list sorted back-to-front. There is **no instancing**; each `LLDrawInfo` is one `glDrawRangeElements` (`LLRenderPass::pushBatch` `lldrawpool.cpp:573-633`) with a per-batch model matrix (`applyModelMatrix`), optional texture matrix, and up to `sIndexedTextureChannels` (4, `llviewershadermgr.cpp:572`) textures bound to units 0..3 with the per-vertex `texture_index` selecting among them.
- Batching rules (`registerFace` `llvovolume.cpp:5600-5905`): consecutive faces in the same VB merge into one `LLDrawInfo` when they share texture (or can batch indices), material hash, fullbright flag, bump, shiny (for materials), texture matrix, model matrix, shader mask, avatar and skin hash. Faces are first bucketed in `rebuildGeom` (`6222-6390`) into simple / fullbright / alpha / bump / norm / spec / normspec / pbr lists; the VB type mask per bucket is at `6419-6450` (alpha adds `MAP_EMISSIVE`, `MAP_TEXTURE_INDEX`, `MAP_TANGENT`, `MAP_TEXCOORD1/2`). `genDrawInfo` (`6632+`) sorts by batch breaker (or distance for alpha), caps a VB at `RenderMaxVBOSize` KB / 65535 verts, and assigns `texture_index` per face while fewer than 4 distinct textures (`can_batch_texture` `5480-5519`: not for bump, materials with maps, invisiprims, animated textures, PBR).
- Vertex formats (`llrender/llvertexbuffer.h:132-166`, sizes `llvertexbuffer.cpp:688-704`, attribute setup `1720-1800`): separate (non-interleaved, one block per attribute) arrays: `position` vec4 (w = **texture index**, written as a float-packed int `llface.cpp:2107-2129`), `normal` vec4 (xyz used), `texcoord0..3` vec2, `diffuse_color` ubyte4 normalised, `emissive` ubyte4 (only alpha = glow used; aliased onto the color slot when color absent), `tangent` vec4 (xyz + sign), `weight` float, `weight4` vec4 (packed joint index + weight, decoded in `objectSkinV.glsl`), `clothing` vec4, `joint` u64, index buffer U16. The stride passed to GL is the per-type size, i.e. attributes are planar.
- Rigged meshes: matrix palette (`MAX_JOINTS_PER_MESH_OBJECT`) uploaded per batch via `uploadMatrixPalette` (`lldrawpool.cpp:685-777`); every pass type has a `_RIGGED` twin (`lldrawpool.h:139-203`) drawn with the shader's `mRiggedVariant`.

## 8. Quirks that must be reproduced for visual equivalence

1. **Mixed colour spaces in the G-buffer.** Legacy diffuse/spec are stored sRGB and linearised in lighting; PBR data is linear; the sky is stored "doubled" (`color*2`, clamp 5) and converted by `sky_hdr_scale`. Any reimplementation must keep the flag-based branch (`normalMap.w`) and the exact `srgb_to_linear` / `linear_to_srgb` (`class1/environment/srgbF.glsl:26-81`, note `linear_to_srgb` clamps to [0,1] first).
2. **Normal encoding** is a spheremap transform with env intensity and a 2-bit-ish float flag in the same RGBA16 texture; the flag thresholds (0, 0.34, 0.67, 1.0 +-0.1) must survive the format you choose.
3. **Alpha channel of `screen` is glow.** Opaque glow and PBR emissive-glow write alpha only; alpha-blended faces *suppress* glow with `(ZERO, ONE_MINUS_SRC_ALPHA)`; emissive alpha faces re-add it with `(ZERO, ONE, ONE, ONE)`; soften/haze/lights write alpha 0; glow extraction ignores luminance (`minLuminance = 9999`) so bloom is purely driven by this channel, and is extracted from the **tonemapped sRGB** image.
4. **Alpha masking rules** (`LLFace::canRenderAsMask` `llface.cpp:1211-1256`): a blended face is promoted to an alpha-mask (`PASS_ALPHA_MASK`, cutoff 0.33 per `mAlphaMaskCutoff`, grass 0.5) when colour alpha == 1, glow == 0, not a HUD, not rigged, no blend material, and the texture is detected as a binary mask, gated by `RenderAutoMaskAlphaDeferred`. Materials with `DIFFUSE_ALPHA_MODE_MASK` use `minimum_alpha - 1/512` bias (`materialF.glsl:253-263`). Fully transparent (alpha 0, no glow) faces are dropped entirely (`llvovolume.cpp:6292-6296`). Faces smaller than `FORCE_SIMPLE_RENDER_AREA` pixels are forced to the simple pool (`6228-6238`).
5. **Fullbright** is encoded as diffuse alpha = 1 ("emissive") in the G-buffer and makes the soften pass output the raw albedo (`mix(color, baseColor, baseColor.a)`); it also forces shadow factor to 1 (`scol = max(lightMap.r, baseColor.a)`), and fullbright *blended* faces multiply by the exposure inverse (bind `exposureMap`) so they come out "unexposed".
6. **Legacy shiny / env intensity**: `applyGlossEnv` halves the probe sample, applies `(1+V.N)^2 * spec.a` fresnel and "fake energy conservation" `*(1-color)`, then adds half again; `applyLegacyEnv` mixes `legacyenv*0.5` by env intensity with a fresnel floor. These magic halves define the look of pre-PBR materials.
7. **Magic gains**: PBR sun `*3.0`, point/spot `*3.25` (deferred) vs `*3.0` (forward helper), `classic_mode` 1.35 sun / 0.9 light / 1.1 final, ambient `pow(.,0.9)*0.57`, haze `additive*2`, probe ambiance mixing, `legacyGamma`. The SL "classic mode" (legacy sky without `reflection_probe_ambiance`) does lighting partly in gamma space (`softenLightF.glsl:226-233`), which is a deliberate look-match to pre-7.0 viewers.
8. **Sun colour normalisation** (max component clamped to 1 on the CPU, `pipeline.cpp:6397-6408`) and the atmosphere's `exp(-light_atten/lightnorm.y)` with `lightnorm.z` clamped >= -0.1: sunset brightness depends on these exactly.
9. **Shadow cascade fitting** is a perspective best-fit with fallbacks to ortho; equivalence of shadow *shape* (penumbra, aliasing) requires replicating the 5-tap PCF with the x-jitter and the 0.75/1.25 cascade overlap; exact cascade *placement* can be replaced by any CSM that covers the same depth ranges without visible difference except at cascade borders.
10. **Post order**: luminance from an off-centre window, exposure as a 1x1 temporal buffer, tonemap *before* glow, dither on present, FXAA after glow and after DoF, DoF at 0.7 res with CoC in alpha. The legacy-sky path has `tonemap_mix = 0` (effectively linear + sRGB + legacy gamma), which most content was authored against.
11. **Sky depth trick**: the dome is drawn at squashed depth 0.99999 and the depth buffer is **cleared** after the sky pool, so later geometry never depth-tests against the sky; haze/present rely on depth == 1 meaning sky.
12. **Water**: no planar reflection; refraction from a copy of the current colour buffer; fog alpha `pow(a,1.7)`; exclusion mask with its own depth; patches re-drawn for haze. Transparent water off => opaque fog colour.
13. **Impostors** are mini G-buffers with a depth-derived alpha mask, updated on angle/distance thresholds; they're drawn in the G-buffer pass as quads with their own normals/spec so they receive deferred lighting.
14. **Reflection probe temporal behaviour**: one face per frame, 12 frames per probe, 2-second fade-ins, irradiance desaturation and ambient zeroing during irradiance faces, automatic probes without parallax. The *result* (slowly converging, slightly stale IBL) is part of the look; exact replication of the scheduler is not needed, but the irradiance/radiance filtering and the weighting/blending (`sampleProbes`, `sphereWeight`) are.
15. **Cheap equivalence**: pass structure, targets, formats, blend states, culling and batching can be redesigned freely (bindless/instancing/descriptor indexing are all fine) as long as the per-pixel maths of `softenLightF`, `pointLight/spotLight/multiPointLight`, `atmosphericsFuncs`, `reflectionProbeF`, `shadowUtil`, `tonemapUtilF`, `glowExtract/glow`, `waterF`, `skyV/skyF/cloudsF` and the alpha/material/PBR forward shaders are ported literally (they are plain GLSL 1.40-era code, easily translated to SPIR-V). **Expensive equivalence** lies in CPU-side policies that feed those shaders: sun-colour normalisation, `setupHWLights` attenuation constants, `calcNearbyLights` selection/fade, `canRenderAsMask`, face bucketing/`registerFace`, LOD selection, probe origin/radius heuristics, exposure parameter selection and the legacy/EEP/auto-adjust branching in `LLSettingsVOSky::applySpecial`.
