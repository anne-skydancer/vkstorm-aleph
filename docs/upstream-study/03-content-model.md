# Firestorm content and material model (reference survey for the Vulkan/Rust viewer)

Source: `C:\Dev\vkstorm-aleph-ref` (Firestorm master as of 2026-10-18, branch `vkstorm-aleph`). All paths below are relative to `indra/`. Line numbers were read from that checkout.

Scope: everything that determines *what geometry* and *what surface parameters* reach the renderer. Frame/pass structure, shader loader, networking and native dependencies are covered by other reports; this one only points at the shaders that consume each material path.

Conventions used throughout:
- World units are meters. Z is up. The engine's coordinate frames are right-handed with X = "at"/forward, Y = left, Z = up (`llmath/llcoordframe.h:104-110`).
- "TE" = texture entry (per-face surface record). "LOD" indices run 0 (lowest) to 3 (highest).

## 1. Geometry sources

### 1a. Procedural prims: LLVolume / LLVolumeParams / LLProfile / LLPath

**Parameter quantization (wire -> float).** `llmath/llvolume.h:75-80`: `CUT_QUANTA=0.00002`, `SCALE_QUANTA=0.01`, `SHEAR_QUANTA=0.01`, `TAPER_QUANTA=0.01`, `REV_QUANTA=0.015`, `HOLLOW_QUANTA=0.00002`. The U8/U16 constructor of `LLPathParams` (`llvolume.h:373-389`) decodes the ObjectUpdate fields:
- `begin = u16 * CUT_QUANTA`, `end = (100 - u16) * CUT_QUANTA` (clamped <= 1)
- `scale = (200 - u8) * SCALE_QUANTA` (x,y) -- this is "hole size"/"top size" (ratio)
- `shear = s8 * SHEAR_QUANTA`, `twistBegin/twistEnd = s8 * SCALE_QUANTA` (range -1..1 == -360..360 deg for circle paths, -180..180 for linear)
- `radiusOffset = s8 * SCALE_QUANTA`, `taper = s8 * TAPER_QUANTA`, `revolutions = u8 * REV_QUANTA + 1`, `skew = s8 * SCALE_QUANTA`
- Profile: `begin = u16*CUT_QUANTA`, `end = (50000 - u16)*CUT_QUANTA`, `hollow = u16*HOLLOW_QUANTA` (`llvolume.h:233-245`).

Valid ranges enforced by `LLVolumeParams::validate` and setters (`llvolume.cpp:64-100`): hollow 0..0.99 (0.70 for square holes), twist -1..1, ratio 0..2, hole X 0.01..1, hole Y 0.01..0.5, shear -0.5..0.5, revolutions 1..4, taper -1..1, skew -0.95..0.95.

**Type codes** (`llvolume.h:139-168`): profile curve low nibble `LL_PCODE_PROFILE_CIRCLE=0, SQUARE=1, ISOTRI=2, EQUALTRI=3, RIGHTTRI=4, CIRCLE_HALF=5`; hole shape high nibble `HOLE_SAME=0x00, CIRCLE=0x10, SQUARE=0x20, TRIANGLE=0x30`; path curve `PATH_LINE=0x10, CIRCLE=0x20, CIRCLE2=0x30, TEST=0x40, FLEXIBLE=0x80`. Sculpt types `llvolume.h:182-200`: `NONE=0, SPHERE=1, TORUS=2, PLANE=3, CYLINDER=4, MESH=5, GLTF=6`, flags `INVERT=64, MIRROR=128`.

**Detail levels.** `LLVolumeLODGroup::mDetailScales[4] = {1.0, 1.5, 2.5, 4.0}` and thresholds `{0.03, 0.06, 0.24, 3.0}` on the tangent of apparent angle (`llmath/llvolumemgr.cpp:30-42`). `getDetailFromTan` picks the first LOD whose threshold >= tan_angle (`llvolumemgr.cpp:328-340`). `MIN_DETAIL_FACES=6` (`llvolume.h:65`). A volume is instantiated per LOD as `new LLVolume(params, mDetailScales[lod])` (`llvolumemgr.cpp:299`).

**Generation pipeline** (`LLVolume::generate`, `llvolume.cpp:2051-2165`):
1. `split = (S32)(detail*0.66)`; forced to 0 for linear-path square/triangle profiles with non-unit scale (`llvolume.cpp:2061-2073`).
2. `mLODScaleBias` = 0.5 for everything, 0.6/0.6/0 for linear-path circles (cylinders ignore Z), 0.6 for circle paths (`llvolume.cpp:2075-2093`). This biases the LOD radius in `LLVOVolume::calcLOD`.
3. `LLPath::generate` then `LLProfile::generate` (`llvolume.cpp:1470-1600`, `751-1028`).
4. Mesh points: for every path point `s` and profile point `t`: `P = (scale(s) * rot(s)) * profile[t] + pos(s)` (`llvolume.cpp:2110-2153`). Profile points are in the XY plane (Z component holds the texture S coordinate), path points carry `mPos`, `mRot` (3x3), `mScale` (x,y), `mTexT`.
5. `createVolumeFaces` builds one `LLVolumeFace` per `LLProfile::Face` (`llvolume.cpp:2798-2943`).

**Profile generation** (`LLProfile::generate`, `llvolume.cpp:751-1028`):
- SQUARE: `genNGon(params, 4, offset=-0.375)` then scale profile Z (tex S) by 4; faces `LL_FACE_OUTER_SIDE_0 << i` for `i in floor(begin*4) .. floor(end*4+0.999)`, each face `addFace(i*(split+1), split+2, scaleU=1, flat=true)`. Hollow: square/same -> `addHole(4 sides, -0.375)`, circle -> `addHole(MIN_DETAIL_FACES*detail)`, triangle -> `addHole(3)` (`llvolume.cpp:789-834`).
- ISOTRI/RIGHTTRI/EQUALTRI: `genNGon(3, offset 0)`, tex S scaled by 3, 3 outer faces; hollow uses `hollow/2` (`llvolume.cpp:836-877`).
- CIRCLE: sides = `MIN_DETAIL_FACES*detail` (6,9,15,24 for the four LODs), snapped to a multiple of 4 when the hole is square; one outer face `LL_FACE_OUTER_SIDE_0` (count `mTotal-1` if open and not hollow); sculpts override `sides` (`llvolume.cpp:878-927`).
- CIRCLE_HALF (sphere): sides = `MIN_DETAIL_FACES*detail*0.5`, `genNGon(sides, offset 0.5, ang_scale 0.5)`; closed non-hollow spheres duplicate point 0 (`llvolume.cpp:928-986`).
- `genNGon` (`llvolume.cpp:472-600`): points at angle `2*pi*(t*ang_scale + offset)` with radius `scale` (0.5, or `tableScale[sides]` = {1,1,1,0.5,0.707,0.53,0.525,0.5} for <8 total sides so shapes fill the bounding box); `split` extra points interpolated between integer steps; fractional begin/end cut points are lerped; cut profiles (`(end-begin)*ang_scale < 0.99`) are `mOpen` and get a center point `(0,0,0)` if not hollow; `mConcave` when more than half remains.
- `addHole` (`llvolume.cpp:602-640`): regenerates an n-gon, scales it by `box_hollow` (hollow is a fraction of the bounding box, not of the outer profile), reverses its order, appends it as `LL_FACE_INNER_SIDE` and doubles the vertex count of cap faces.
- After the switch: if path is open, `addCap(LL_FACE_PATH_END)`; if the profile is open (cut), two flat 2-point faces `LL_FACE_PROFILE_BEGIN` and `LL_FACE_PROFILE_END` (`llvolume.cpp:992-1012`).
- Face order (== TE index order; `LLVOVolume::addFace(i)` for `i < getNumTEs()`, `newview/llvovolume.cpp:1158-1180`): `[PATH_BEGIN cap]`, outer sides..., `[INNER_SIDE if hollow]`, `[PATH_END cap]`, `[PROFILE_BEGIN, PROFILE_END if cut]`. NOTE: `TOP_MASK` is assigned to the `LL_FACE_PATH_BEGIN` cap and its vertices come from the *last* path row (`llvolume.cpp:6193-6200`), i.e. face 0 is the +Z top. The code order places the hollow inner face *before* the bottom cap; verify empirically against the SL face-numbering convention before relying on it.

**Path generation** (`LLPath::generate`, `llvolume.cpp:1470-1600`):
- LINE: `np = floor(|twistBegin-twist| * 3.5 * (detail-0.5)) + 2`, at least `split+2`; point `i`: `t = lerp(begin,end,i/(np-1))`, `pos = (lerp(0,shearX,t), lerp(0,shearY,t), t-0.5)`, rotation about Z by `lerp(pi*twistBegin, pi*twist, t)`, scale = lerp(beginScale, endScale) where `getBeginScale/getEndScale` (`llvolume.cpp:1394-1420`) map ratio>1 to a shrunken start and ratio<1 to a shrunken end (taper), `mTexT = t`.
- CIRCLE (torus/tube/ring): `sides = floor(floor(6*detail + twist_mag*3.5*(detail-0.5)) * revolutions)`; `genNGon` (`llvolume.cpp:1234-1392`): `hole_x = scaleX*(1-|skew|)`, `hole_y = scaleY`; radius 0.5 (table for <8 sides) times `(1-hole_y)`, with `radiusOffset` shrinking start or end radius; `ang = 2*pi*revolutions*t`; `pos = (shearX*s + lerp(-skew,skew,t)*0.5, c + shearY*s, s)` where `c,s = cos/sin(ang)*radius(t)`; `scale = (hole_x*lerp(taperXbegin,taperXend,t), hole_y*...)`; rotation = `twist(z, lerp(twistBegin,twistEnd,t)*2pi - pi) * rot(ang about X)`. First and last points are placed exactly at begin/end; interior points are snapped to `1/sides` steps so cut doesn't move them. `mOpen` when cut, skewed, tapered or radius-offset.
- CIRCLE2 and TEST are legacy/unused shapes (`llvolume.cpp:1562-1596`).
- FLEXIBLE: `LLDynamicPath::generate` (`llvolume.cpp:1603-1626`) only seeds 2 identity points; the path is written by the flexible simulation (section 1e).

**Face mesh building** (`LLVolumeFace::create`, `llvolume.cpp:5146-5171`, dispatching to `createCap`/`createSide`):
- `createSide` (`llvolume.cpp:6660-7200`): `num_vertices = mNumS*mNumT`, `num_indices = (mNumS-1)*(mNumT-1)*6`. Vertex `(s,t)` = `mesh[mBeginS + s + max_s*t]` (wrapping when `mBeginS+s >= max_s`). Texcoord: `ss = profile[index].z` (the n-gon tex S, minus `floor(profile[mBeginS].z)` for flat faces), `tt = path[t].mTexT`; END (cut) faces use `ss = 0/1`; sculpt mirror/invert XOR flips `ss = 1-ss`. Indices per quad: `(s,t),(s+1,t+1),(s,t+1)` and `(s,t),(s+1,t),(s+1,t+1)` (`llvolume.cpp:6830-6845`). Normals: accumulated face normals, then wrapped across the T seam if path closed, across S seam if profile closed, special-cased for spheres (poles get +/-X normals) and sculpts (poles averaged, seams wrapped per stitching type) (`llvolume.cpp:6960-7190`). Flat inner (hollow) faces duplicate vertices so each strip gets flat normals (`llvolume.cpp:2865-2875`, `6683-6760`).
- `createCap` (`llvolume.cpp:6162-6615`): uncut, non-hollow linear-path cubes get `createUnCutCubeCap` (a `(grid_size+1)^2` planar grid, uv from profile `(x+0.5, 0.5-y)`, top face UVs swapped on U, `llvolume.cpp:6022-6160`); otherwise one vertex per profile point plus a center vertex if closed; UV = `(px+0.5, py+0.5)` for TOP, `(px+0.5, 0.5-py)` for bottom; triangulation is a fan from the center or, for hollow caps, an ear-clipping walk between outer and inner rings; one flat normal from the first triangle.
- Tangents: `LLVolumeFace::createTangents` / `LLCalculateTangentArray` (`llvolume.cpp:6417-6440`, `7205-7300`) is Lengyel's per-triangle accumulation with Gram-Schmidt and handedness in `w`; generated lazily (`LLVolume::genTangents`) when a face needs bump/normal maps or planar texgen.
- Mesh assets regenerate tangents in `cacheOptimize(true)` using `mNormalizedScale` (`llvolume.cpp:2719`, `llvolume.h:1002`).

**LLVolumeFace layout** (`llvolume.h:832-1008`): `mPositions`, `mNormals`, `mTexCoords` in one 64-byte aligned block (`resizeVertices`, `llvolume.cpp:6441-6480`), `mTangents` (vec4, w = sign), `mIndices` (U16 triangles), `mWeights` (vec4 of `joint_index + weight`), `mExtents[2]`, `mCenter`, `mTexCoordExtents[2]`, `mTypeMask` bits (`CAP, END, SIDE, INNER, OUTER, HOLLOW, OPEN, FLAT, TOP, BOTTOM`), `mBeginS/mNumS/mBeginT/mNumT`.

**Sculpted prims** (`LLVolume::sculpt`, `llvolume.cpp:3205-3287`): resolution from `sculpt_calc_mesh_resolution` (`llvolume.cpp:3170-3203`): `max_lod_verts = sculpt_sides(detail)^2` with sides 6/8/16/32 for detail <=1/<=2/<=3/else, `max_map_verts = w*h/4`, aspect-matched `s x t` grid (min 4). Path/profile are regenerated with those sizes (circle path, circle profile). `sculptGenerateMapVertices` (`llvolume.cpp:3050-3138`): vertex `(s,t)` samples map pixel `x = reversed_t/(sizeT-1)*w`, `y = s/(sizeS-1)*h`, RGB -> `(c/255 - 0.5)` per axis. Stitching: SPHERE pinches top/bottom rows to the map center column and wraps X; TORUS wraps X and Y; CYLINDER wraps X; PLANE clamps. MIRROR negates X; INVERT (and mirror) flip the horizontal order (`reverse_horizontal = invert XOR mirror`). Surface area outside `[0.002, 384]` (`llvolume.cpp:102`, `3250`) forces a placeholder (sphere of radius 0.3 if `visible_placeholder`). The sculpt texture is fetched as a normal texture; `LLVOVolume::sculpt` (`newview/llvovolume.cpp:1498-1606`) feeds the raw image (any discard level <= `MAX_DISCARD_LEVEL`) and sets `mSculptLevel` to the discard level.

### 1b. Mesh assets

**Asset container** (written by `LLModel::writeModel`, `llprimitive/llmodel.cpp:1130-1210`; read by `LLMeshRepoThread::headerReceived`, `newview/llmeshrepository.cpp:2304-2420`): a binary-LLSD header map followed by concatenated zlib blocks. Header keys (`LLMeshHeader::fromLLSD`, `llmeshrepository.h:331-358`): `version` (int; must be <= `MAX_MESH_VERSION`=999, `llmeshrepository.cpp:391`), and for each of `lowest_lod`, `low_lod`, `medium_lod`, `high_lod`, `physics_mesh`, `physics_convex`, `skin`: `{offset, size}` (offset relative to the end of the header; `-1`/`0` = absent). Optional `404`, `creator`, `date`, `submodel_id`. A deprecated textual prefix is stripped by `strip_deprecated_header` (`llmeshrepository.cpp:2322`).

**LOD block** (`LLVolume::unpackVolumeFacesInternal`, `llmath/llvolume.cpp:2341-2732`): zlib-inflated binary LLSD array, one map per face (max 8 faces, `LL_SCULPT_MESH_MAX_FACES`, `llvolume.h:202`):
- `NoGeometry` -> degenerate face.
- `Position`: U16 x3 per vertex, dequantized `v/65535 * (Max-Min) + Min` using `PositionDomain{Min,Max}` (`llvolume.cpp:2462-2473`).
- `Normal`: U16 x3, `n/65535*2-1` (`llvolume.cpp:2478-2495`).
- `TexCoord0`: U16 x2, dequantized with `TexCoord0Domain{Min,Max}` (`llvolume.cpp:2530-2560`).
- `TriangleList`: U16 indices, triplets (non-multiple-of-3 tail discarded).
- `NormalizedScale`: vec3, the scale applied when the source was normalized to the unit cube (used for tangent regeneration).
- `Weights` (rigged only, `llvolume.cpp:2562-2622`): per vertex a run of `(U8 joint, U16 weight)` pairs terminated by joint `0xFF`, max 4 influences; weight = `clamp(u16/65535, 0.001, 0.999)`; stored as `float = joint_index + weight` in `mWeights[v]` (all-zero weights become `(0.999,0,0,0)`).
- `Tangent` is parsed only under `#if 0` (`llvolume.cpp:2498-2525`): tangents are always regenerated by the viewer.
- Sculpt flags `MIRROR` reflect X (positions and normals negated) and reverse winding; `INVERT` flips normals and reverses winding (`llvolume.cpp:2625-2680`).
- After decode: bounding box, texcoord extents, then `cacheOptimize(true)` (meshoptimizer vertex-cache/overdraw/fetch optimization + tangent generation).

**Skin block** (`LLMeshSkinInfo::fromLLSD`, `llprimitive/llmodel.cpp:1671-1759`): `joint_names` (array of strings), `inverse_bind_matrix` (array of 16-float row-major arrays, one per joint), `bind_shape_matrix` (16 floats), `alt_inverse_bind_matrix` (per joint; used to pose joints for "joint position" rigs), `pelvis_offset` (float), `lock_scale_if_joint_position` (bool). `mBindPoseMatrix[i] = bind_shape * inv_bind[i]` is precomputed (`llmodel.cpp:1751-1756`). Joint name/matrix count mismatch drops the rig. Invalid joint names are rewritten to `mPelvis` (`newview/llskinningutil.cpp:116-131`).

**Physics blocks** (`LLModel::Decomposition::fromLLSD`, `llmodel.cpp:1883-1970`): `physics_convex` map with `HullList` (U8 vertex count per hull, 0 means 256), `Positions` (U16 x3 per point dequantized by `Min`/`Max`, default +/-0.5 cube) and/or `BoundingVerts` (single hull); `physics_mesh` is a LOD-format block (`LLModel::loadModel` treats `lod==4` as physics, `llmodel.cpp:1377-1420`). Not needed for rendering except the physics-shape display.

**LOD selection.** `LLVOVolume::calcLOD` (`newview/llvovolume.cpp:1664-1830`): `distance = mDrawable->mDistanceWRTCamera * sDistanceFactor`, boosted when `< 2*sLODFactor` (quadratic ramp), then `*= pi/3`; `radius = |mLODScaleBias .* getScale()|` (for rigged meshes: the avatar's animated bounding box diagonal, x1 for animesh, "x2" for regular attachments, `llvovolume.cpp:1687-1718`); `lod_factor = RenderVolumeLODFactor` (`sLODFactor`) optionally scaled by `DEFAULT_FOV/currentFOV`; `computeLODDetail` (`llvovolume.cpp:1608-1621`): `tan_angle = lod_factor*radius/distance` -> `LLVolumeLODGroup::getDetailFromTan`. HUD attachments always LOD 3. `LLVOVolume::setVolume` (`llvovolume.cpp:1229-1360`) maps the requested LOD to the best available block via `LLMeshRepository::getActualMeshLOD` (`llmeshrepository.cpp:3610-3652`: exact, else next lower, else next higher; none -> 404 and the prim renders as its underlying prim shape with a mesh icon). `LLVolume::getLoDTriangleCounts` (`llvolume.cpp:3722-3760`) is the streaming-cost estimator.

### 1c. Avatar mesh

- **Definitions**: `newview/character/avatar_skeleton.xml` (`<linden_skeleton num_bones="133" num_collision_volumes="26" version="2.0">`, nested `<bone name pos rot scale pivot end group support="base|extended">` and `<collision_volume>`), and `newview/character/avatar_lad.xml` (`<skeleton>` with `<param_skeleton>` scale/offset drivers, 31 `<mesh type=.. lod=.. file_name=.. reference=.. min_pixel_width=..>` nodes, `<global_color>`, 11 `<layer_set>`s (texture bake compositing), `<morph_masks>`, `<driver_parameters>` with 164 `<param_driver>`; 705 `<param>`s overall including 255 `<param_morph>`, 83 `<param_skeleton>`, 108 `<param_color>`, 95 `<param_alpha>`). Parsed by `LLAvatarAppearance::loadAvatar` (`llappearance/llavatarappearance.cpp:901-1033`) and `loadMeshNodes` (`:1096-1210`, LOD `mMinPixelArea` from `min_pixel_width^2`).
- **.llm files** (`LLPolyMeshSharedData::loadMesh`, `llappearance/llpolymesh.cpp:290-650`): 128-byte header `"Linden Binary Mesh 1.0"`, `hasWeights:U8`, `hasDetailTexCoords:U8`, `position:3f`, `rotationAngles:3f`, `rotationOrder:U8`, `scale:3f`, `numVertices:U16`, then arrays: coords (3f), normals (3f), binormals (3f), texcoords (2f), detail texcoords (2f, optional), weights (1f per vertex, optional), `numFaces:U16` + faces (3xU16), `numSkinJoints:U16` + joint names (64-char), then morph blocks: 64-char name + `LLPolyMorphData::loadBinary` (`llpolymorph.cpp:107-200`: `numVertices:S32`, per vertex `index:U32`, `coord:3f`, `normal:3f`, `binormal:3f`, `texcoord:2f`), optional remaps. LOD files `avatar_*_1..4.llm` reference the base mesh (`reference=` attribute).
- **Morphs / visual params**: `LLPolyMorphTarget` applies `mCoords/mNormals/mBinormals/mTexCoords` deltas scaled by the param weight (with optional morph masks) to the shared mesh; `LLPolySkeletalDistortion` (param_skeleton) scales/offsets joints; `LLDriverParam` chains them. Wearables (section 5) carry param values.
- **System body skinning**: `weight` attribute is one float per vertex = `joint_index + fraction` blending between joint `i` and `i+1` of the mesh's joint list (`avatarSkinV.glsl`, `newview/app_settings/shaders/class1/avatar/avatarSkinV.glsl:30-46`: `matrixPalette[45]` = 15 joints x 3 rows, `LL_CHARACTER_MAX_JOINTS_PER_MESH = 15`, `llcharacter/lljoint.h:43`). Palette upload in `LLViewerJointMesh::uploadJointMatrices` (`newview/llviewerjointmesh.cpp:100-190`): `joint_world * modelview`, translated by the skin pivot (`mRootToJointSkinOffset`), transposed, uploaded as 3 vec4 rows per joint. Avatar vertex format: `LLDrawPoolAvatar::VERTEX_DATA_MASK = VERTEX|NORMAL|TEXCOORD0|WEIGHT|CLOTHWEIGHT` (`newview/lldrawpoolavatar.h:50-54`); `clothing` vec4 drives the optional wind "AVATAR_CLOTH" effect in `class1/deferred/avatarV.glsl`.
- **Rigged attachments**: `LLSkinningUtil` (`newview/llskinningutil.cpp`): `getMaxJointCount() = LL_MAX_JOINTS_PER_MESH_OBJECT = 110` (`lljoint.h:48`); `LL_CHARACTER_MAX_ANIMATED_JOINTS = 216` (`lljoint.h:47`); `initSkinningMatrixPalette` (`:140-185`): `mat[j] = inv_bind[j] * joint_world[j]` (row-vector convention, `matMulUnsafe(invBind, world, out)`); per-vertex: `getPerVertexSkinMatrix` (`:216-252`) `idx = floor(w)`, `wght = frac(w)` renormalized to sum 1. GPU path `objectSkinV.glsl` (`class1/avatar/objectSkinV.glsl:26-62`): `uniform mat3x4 matrixPalette[MAX_JOINTS_PER_MESH_OBJECT]`, `index = floor(weight4)`, `w = fract(weight4)/sum`, blends the 3x3 and translation separately. Uploaded by `LLRenderPass::uploadMatrixPalette` (`newview/lldrawpool.cpp:651-720`) from `LLVOAvatar::updateSkinInfoMatrixPalette` (`newview/llvoavatar.cpp:11318-11360`, cached per skin hash per frame, 12 floats per joint). `bind_shape_matrix` is *not* applied in the GPU path (it is folded into the inverse bind matrices at upload; the CPU `LLRiggedVolume::update` at `llvovolume.cpp:5240-5370` applies `bind_shape_matrix` explicitly for picking/bounds). Rigged draw calls ignore the object's model matrix (`llvovolume.cpp:5673-5677`).

### 1d. Terrain, water, sky

**Terrain surface** (`LLSurface`, `newview/llsurface.cpp`): per region a `(grids_per_edge+1)^2` height grid `mSurfaceZ` and normals `mNorm` (`:148-200`); `mMetersPerGrid = width/grids_per_edge` (1 m for a 256 m region with 256 grids), patches of `grids_per_patch_edge` (16) -> 16x16 patches. Neighbors are stitched by `connectNeighbor` (`:369-480`).

**LayerData decoding**: `process_layer_data` (`newview/llviewermessage.cpp:553`) -> `LLSurface::decompressDCTPatch` (`llsurface.cpp:868-947`): bit-packed stream (`llmessage/patch_code.cpp`): group header `stride:U16, patch_size:U8, layer_type:U8` (`:206-229`); per patch header `quant_wbits:U8` (0x97 = END_OF_PATCHES; low nibble+2 = word bits, high nibble+2 = prequant), `dc_offset:F32`, `range:U16`, `patchids:10 bits` (`i = id>>5`, `j = id&0x1F`; 32-bit ids for "large" Aurora/OpenSim patches) (`:233-310`); coefficients via `decode_patch` (`:312+`, zig-zag with EOB/sign/magnitude codes). `decompress_patch` (`llmessage/patch_idct.cpp:590-635`): dequantize with `gPatchDequantizeTable` and de-zigzag matrix, 16x16 (or large) IDCT, then `z = coeff*mult + addval` with `mult = range/2^prequant`, `addval = mult*2^(prequant-1) + dc_offset`. Layer types in `patch_dct.h` (LAND, WIND, CLOUD, WATER and the Aurora large variants).

**Terrain geometry** (`LLVOSurfacePatch::updateMainGeometry`, `newview/llvosurfacepatch.cpp:283-384`): a grid of `patch_size/render_stride + 1` vertices with alternating diagonal triangulation; north/east strips handle LOD seams. `LLSurfacePatch::eval` (`newview/llsurfacepatch.cpp:228-268`): `vertex = origin + (x,y)*metersPerGrid`, `z = mDataZ`, `tex0 = region-relative position / region width` (ownership overlay), `tex1.x = composition value at (x,y)`, `tex1.y = noise2(global position * (1/(4.9215*7)) * 0.2222) * 0.75 + 0.5`. LOD: `updateVisibility` (`llsurfacepatch.cpp:1138-1220`) chooses a power-of-two render stride from `distance * 0.15 / metersPerGrid`. Normals: `calcNormal` central differences across neighbors (`:272-422`). Vertex mask: `VERTEX|NORMAL|TANGENT(PBR)|TEXCOORD0|TEXCOORD1` (`newview/lldrawpoolterrain.h:38-42`).

**Legacy 4-texture composition** (`LLVLComposition`): 4 detail textures (defaults dirt/grass/mountain/rock, `newview/llvlcomposition.cpp:416-425`), per-corner `mStartHeight`/`mHeightRange` (SW,SE,NW,NE; from RegionHandshake). `generateHeights` (`:461-563`): bilinear start/range, `height = surface z`, noise `twiddle = (noise2(v*0.222)*6.5 + turbulence2(v,2)*2.25) * 2` where `v = (global xy/4.9215, z/4)`, `comp = clamp((height + twiddle - start) * 4 / range, 0, 3)`. ### 2a. LLTextureEntry

Fields (`llprimitive/lltextureentry.h:216-250`): `mID` (texture UUID), `mColor` (RGBA, sRGB, alpha = face transparency), `mScaleS/T`, `mOffsetS/T`, `mRotation` (radians, counter-clockwise about the face centre), `mBump` (U8: bits 0-4 bump index 0..31, bit 5 fullbright, bits 6-7 shiny 0..3; `lltextureentry.h:48-57`), `mMediaFlags` (bit 0 has-media, bits 1-2 texgen: `TEX_GEN_DEFAULT=0, PLANAR=2` (spherical/cylindrical defined but unused), `:60-80`), `mGlow` (0..1), `mMaterialID` (legacy material hash id), `mMaterial` (resolved `LLMaterial`), `mGLTFMaterial` (asset), `mGLTFMaterialOverrides`, `mGLTFRenderMaterial` (asset + overrides, always an `LLFetchedGLTFMaterial`), `mMediaEntry`.

### 2b. Legacy materials (LLMaterial)

`llprimitive/llmaterial.h:38-150`: `mNormalID` + offset/repeat/rotation, `mSpecularID` + offset/repeat/rotation, `mSpecularLightColor` (RGBA8, default `0.2*255` exponent), `mSpecularLightExponent` (U8), `mEnvironmentIntensity` (U8), `mDiffuseAlphaMode` (`NONE=0, BLEND=1, MASK=2, EMISSIVE=3`; `DEFAULT=4` is a viewer-side "use the material's" value), `mAlphaMaskCutoff` (U8). LLSD/cap encoding (`RenderMaterials` cap, keys in `llmaterial.cpp:35-53`: `NormMap, NormOffsetX/Y, NormRepeatX/Y, NormRotation, SpecMap, Spec*, SpecColor, SpecExp, EnvIntensity, AlphaMaskCutoff, DiffuseAlphaMode`; floats are integers scaled by `MATERIALS_MULTIPLIER`, `llmaterial.cpp:328-400`). `getShaderMask` (`llmaterial.cpp:430-465`): bits 0-1 alpha mode, bit 2 has specular map, bit 3 has normal map -> indexes the 16 material shader variants / pass table (`newview/llvovolume.cpp:7040-7087`).

Reaching the shader (`LLVolumeGeometryManager::registerFace`, `llvovolume.cpp:5600-5900`; `LLDrawPoolMaterials::pushMaterialsBatch`, `newview/lldrawpoolmaterials.cpp:140-290`): `LLDrawInfo::mSpecColor = (specColor/255, exponent/255)`, `mEnvIntensity = envIntensity/255`, `mAlphaMaskCutoff = cutoff/255`, `mNormalMap`, `mSpecularMap`, `mFullbright` -> uniforms `specular_color` (vec4), `env_intensity`, `minimum_alpha`, `emissive_brightness` (fullbright flag), samplers `diffuseMap`, `bumpMap`, `specularMap`, plus `texture_matrix0` for texture animation. Without a material: `specColor = envIntensity = {0, .25, .5, .75}[shiny]` (`llvovolume.cpp:5820-5830`) and shininess is baked into the vertex colour alpha when no specular map is present (`newview/llface.cpp:1470-1500`); `diffuseF.glsl` writes `vertex_color.a` as both spec and env intensity (`class1/deferred/diffuseF.glsl`).

Consuming shaders: `class1/deferred/materialV.glsl` + `class3/deferred/materialF.glsl` (compiled 16 ways with `DIFFUSE_ALPHA_MODE`, `HAS_NORMAL_MAP`, `HAS_SPECULAR_MAP`, `HAS_SKIN`): normal map `vNt*2-1` in a TBN built from `tangent.xyz` and `sign*cross(N,T)`; `glossiness = specular_color.a * normalmap.a`; `spec = specularMap * specular_color.rgb` (or `specular_color` with alpha 1); emissive = `emissive_brightness` or `max(diffuse.a, emissive_brightness)` in EMISSIVE mode; MASK discards below `minimum_alpha - 1/512`. Opaque/masked -> gbuffer: `frag_data[0] = (diffuse sRGB, emissive)`, `frag_data[1] = (spec sRGB, glossiness)`, `frag_data[2] = encodeNormal(n, env, GBUFFER_FLAG_HAS_ATMOS)`. BLEND -> forward lit in the same shader (Blinn-Phong with the `lightFunc` lookup texture and up to 7 local lights). `class1/deferred/bumpV/F.glsl` handles legacy bump (index < 18) without normal maps (`PASS_BUMP`), `diffuseF`, `fullbrightF`, `emissiveF` (glow pass uses the `emissive` vertex attribute), `class2/deferred/alphaF.glsl` for plain alpha-blended faces.

Legacy bump indices (`newview/lldrawpoolbump.h:88-95`, `.cpp:93-170`): `0=none`, `1=brightness`, `2=darkness` (derived from the diffuse texture by `LLBumpImageList::getBrightnessDarknessImage`, `lldrawpoolbump.cpp:754-900`), `3..17` the 15 standard bump textures from `app_settings/std_bump.ini` (woodgrain, bark, bricks, checker, concrete, crustytile, cutstone, discs, gravel, petridish, siding, stonetile, stucco, suction, weave; each a texture UUID), all converted to normal maps (`normgenF.glsl`). The pipeline treats `bump != 0 && bump < 18` as "legacy emboss bump" (`llvovolume.cpp:6345`, `6953`); the 5-bit field allows up to 31 but nothing above 17 is defined. Emboss offsets for brightness/darkness are computed per face in `llface.cpp:1657-1718` using the sun/moon direction.

### 2c. GLTF PBR materials

`llprimitive/llgltfmaterial.h:50-294`: `mTextureId[4]` (`BASE_COLOR, NORMAL, METALLIC_ROUGHNESS (occlusion shares it: ORM packed), EMISSIVE`), `mTextureTransform[4]` (`mOffset, mScale, mRotation` from `KHR_texture_transform`), `mBaseColor` (RGBA, **linear**), `mEmissiveColor` (linear), `mMetallicFactor`, `mRoughnessFactor`, `mAlphaCutoff` (default 0.5), `mAlphaMode` (`OPAQUE=0, BLEND, MASK`), `mDoubleSided`, override-only flags `mOverrideDoubleSided`, `mOverrideAlphaMode`. Binding (`LLFetchedGLTFMaterial::bind`, `newview/llfetchedgltfmaterial.cpp:64-145`): `minimum_alpha` (= cutoff for MASK else -1), `diffuseMap` = base colour (or media texture), `bumpMap` = normal (flat default), `specularMap` = ORM (white default), `emissiveMap` (white default), `roughnessFactor`, `metallicFactor`, `emissiveColor`, and four `texture_*_transform` as `vec4[2] = {scale.xy, rotation, 0, offset.xy, 0, 0}` (`getPacked`, `llgltfmaterial.cpp:84-93`). Texture transform helper (`class1/deferred/textureUtilV.glsl:25-75`): `texture_transform(uv, khr, anim)`: apply the SL animation matrix first, flip `v = 1-v`, apply KHR `offset * rotation * scale` (rotation matrix as in the KHR sample), flip back. `tangent_space_transform` rotates the tangent by the inverse rotation and scale sign. Legacy<->PBR transform conversion for the UI: `convertTextureTransformToPBR` (`llgltfmaterial.cpp:955-1005`: PBR rotation = -legacy rotation, scale approximated with cos^2/sin^2 mixing, offset rotated about the tile centre; `pbr_offset.y = ... - tex_offset_t`).

### 2d. Texture animation

`LLTextureAnim` (`llprimitive/lltextureanim.h:49-70`, wire `TextureAnim` 16-byte block: `mode:U8, face:S8 (-1 = all), sizeX:U8, sizeY:U8, start:F32, length:F32, rate:F32` (frames/s)); mode bits `ON=1, LOOP=2, REVERSE=4, PING_PONG=8, SMOOTH=0x10, ROTATE=0x20, SCALE=0x40`. `LLViewerTextureAnim::animateTextures` (`newview/llviewertextureanim.cpp:60-200`): frame counter from elapsed time * rate (continuous for SMOOTH, integer otherwise), loop/ping-pong/reverse handling, `+start`; ROTATE -> `rot = frame`, SCALE -> `scale = frame`, otherwise TRANSLATE: with a grid, `scale = 1/sizeX, 1/sizeY`, `off_s = -0.5 + 0.5*scale_s + (frame mod sizeX)*scale_s`, `off_t = 0.5 - 0.5*scale_t - floor(frame/sizeX)*scale_t`; without a grid `off_s = -0.5 + 0.5 + frame`. `LLVOVolume::animateTextures` (`newview/llvovolume.cpp:723-848`) builds `LLFace::mTextureMatrix = T(off+0.5) * S(scale) * R(-rot about Z) * T(-0.5)` for each animated face (non-animated TE components come from the TE), which `registerFace` passes as `LLDrawInfo::mTextureMatrix` and the pools load as `texture_matrix0` (`lldrawpoolmaterials.cpp:263-270`). Vertex shaders apply `texture_matrix0` to `texcoord0` (and `texcoord1/2`); PBR shaders pass it as `sl_animation_transform`. When the face is small (`MIN_TEX_ANIM_SIZE`) the animated offsets are baked into the TE instead.

Static TE transforms are baked into `texcoord0` at geometry build time: `LLFace::getGeometryVolume` (`newview/llface.cpp:1774-1900`) uses `xform4a` (`:788-830`): `st = (uv - 0.5) rotated by (cos,sin) of rotation, * scale, + offset + 0.5`. Planar texgen (`planarProjection`, `llface.cpp:93-126`): binormal chosen from the dominant normal axis, `tangent = binormal x normal`, `u = 1 + (2*dot(binormal,P) - 0.5)`, `v = -(2*dot(tangent,P) - 0.5)` using the vertex position relative to the face centre (planar faces repeat once per 2 m before the TE scale). Bump/normal-map texcoords (`texcoord1`) and specular (`texcoord2`) are the diffuse coords transformed by the material's own offset/repeat/rotation (`llface.cpp:1907-2000`).

### 2e. Shininess / environment reflections

- Legacy "shiny" (TE shiny 0..3) -> environment intensity `{0, .25, .5, .75}` stored in the vertex colour alpha (no specular map) or `env_intensity` uniform (materials). Deferred: written to the gbuffer normal buffer's blue channel (`encodeNormal(n, env, flag)`, `class1/deferred/globalF.glsl:46-61`: Lambert azimuthal-ish packing `n.xy/sqrt(8*n.z+8)+0.5`, `z = env`, `w = flag`). `softenLightF.glsl` (`class3/deferred/softenLightF.glsl`) resolves legacy pixels with `sampleReflectionProbesLegacy` (`class3/deferred/reflectionProbeF.glsl:842-890`): `ambenv` from probe irradiance (or `amblit` in classic mode), `glossenv = probe radiance at lod (1-glossiness)*max_lod` when `spec.a > 0`, `legacyenv = probe radiance at lod 0` when `envIntensity > 0`; `applyGlossEnv` (`:893-902`, fresnel-weighted, x0.5) and `applyLegacyEnv` (`:904-913`: `color = mix(color, reflected*0.5, envIntensity)` with fresnel `min((1+dot(view,n))^2 + env, 1)`). Forward fullbright-shiny (`class3/deferred/fullbrightShinyF.glsl`) does the same with the probe system; the old `environmentMap` cube uniform is still declared (`lldrawpoolbump.cpp:228-268`) but the probe path is what renders in the deferred pipeline.
- PBR: `GBUFFER_FLAG_HAS_PBR` pixels use `sampleReflectionProbes` (irradiance + radiance by gloss) and `pbrIbl`/`pbrPunctual` (`deferredUtil.glsl`: split-sum with `brdfLut`, Cook-Torrance with Schlick fresnel, Smith-style geometric term, GGX distribution; `calcDiffuseSpecular` with F0 = 0.04).
- Reflection probes themselves (manual probes from `LLReflectionProbeParams`, automatic probes, `reflection_probe_ambiance`) are managed by `LLReflectionMapManager` (frame-structure report).

### 2f. sRGB / linear conventions

- Diffuse / base-colour / emissive textures are sRGB-encoded 8-bit textures sampled as plain (non-sRGB) GL textures; the shaders call `srgb_to_linear` explicitly (`class1/environment/srgbF.glsl:27-60`, exact piecewise sRGB curve; `linear_to_srgb` uses exponent 0.41666). Normal maps and ORM are linear.
- Legacy path: gbuffer colour (`frag_data[0]`) and spec (`frag_data[1]`) are written **sRGB** (`materialF.glsl` comment "gbuffer is sRGB for legacy materials"); `softenLightF.glsl` linearizes them before lighting. Alpha-blended legacy faces linearize in the forward shader. Vertex colours (`diffuse_color`) are sRGB TE colours multiplied *before* linearization (so `srgb(tex*color)`), as noted in `alphaF.glsl` ("vertex color should be treated as sRGB").
- PBR path: base colour texture is linearized then multiplied by the (linear) base colour factor; gbuffer stores linear colour; emissive factor is linear and the emissive map is linearized.
- Lighting is done in linear space; `calcAtmosphericVarsLinear` (`class1/windlight/atmosphericsFuncs.glsl:85-105`) linearizes `sunlit`, `amblit` (and desaturates ambient to luminance) unless `classic_mode`, and scales by `sky_sunlight_scale` / `sky_ambient_scale` (`RenderSkySunlightScale`, `RenderSkyAmbientScale`, `newview/llsettingsvo.cpp:795-820`). `additive` haze is linearized in `atmosFragLighting` (`atmosphericsF.glsl`: `srgb_to_linear(additive*2) * sky_hdr_scale`).
- `gamma` uniform (`LLSettingsSky` "gamma", `llsettingsvo.cpp:869`) is now only used in the post-process `postDeferredGammaCorrect.glsl` legacy soft-clip and in `sky_hdr_scale = sqrt(gamma)*2` for probe-ambiance skies (`llsettingsvo.cpp:822-828`); the old `scaleSoftClip*` functions in `gammaF.glsl` are identity stubs. CPU-side equivalents: `LLSettingsSky::gammaCorrect` / `clampColor` (`llinventory/llsettingssky.cpp:1617-1635`, `1689-1704`).
- `classic_mode` (`LLSettingsVOSky::applySpecial`, `llsettingsvo.cpp:792-800`): true for legacy (non-probe-ambiance) skies unless `RenderSkyAutoAdjustLegacy`; it switches lighting to the pre-7.0 "Blinn-Phong look" branches in `materialF.glsl`, `softenLightF.glsl`, `alphaF.glsl`, `pbrBaseLight` (`deferredUtil.glsl`), with `sunlit *= 1.35`, `da = pow(da,1.2)`, `0.9/0.7/1.1` scale factors. Both branches must be reproduced for visual equivalence.
- Light colours: `LLLightParams::mColor` is linear (`getSRGBColor` converts for UI); point lights are multiplied by `light_scale` and, for PBR, `*3.0` (`deferredUtil.glsl pbrCalcPointLightOrSpotLight`).
- Textures sampled as sRGB by name: `diffuseMap` ("always in sRGB space"), `emissiveMap`, projector maps (`getTexture2DLod*` in `deferredUtil.glsl` linearize), water `specular` colour, cloud/sky outputs are multiplied by 2 then linearized in the resolve (`GBUFFER_FLAG_SKIP_ATMOS` branch of `softenLightF.glsl`).

## 4. Camera, scale, coordinate systems

- Units are meters; region = 256 m square (`llcommon/indra_constants.h:37-41`, `REGION_HEIGHT_METERS = 4096`). Global positions are `LLVector3d` (doubles) = region origin (from the 64-bit region handle, `from_region_handle`) + region-local `LLVector3`; "agent" coordinates are relative to the agent region's origin (`LLViewerRegion::getPosRegionFromGlobal/getPosGlobalFromRegion`, `newview/llviewerregion.h:331-334`). Rendering uses agent-space positions with per-region `mRenderMatrix` for static drawables (`llvovolume.cpp:5680-5692`).
- Axes: Z up, X east/forward, Y north/left (right-handed). `LLCamera`/`LLCoordFrame`: `mXAxis = at`, `mYAxis = left`, `mZAxis = up` (`llmath/llcoordframe.h:104-110`). The OpenGL view uses `OGL_TO_CFR_ROTATION` (`llrender/llrender.h:553-556`: -Z -> X, -X -> Y, Y -> Z), so eye space is the usual GL -Z forward; `LLViewerCamera::setPerspective` (`newview/llviewercamera.cpp:294-420`) builds `proj = glm::perspective(fov_y, aspect, near, far)` (with pick/zoom-subregion adjustments) and `modelview = OGL_TO_CFR * getOpenGLTransform()`.
- FOV: `DEFAULT_FIELD_OF_VIEW = 60 deg` vertical (`llmath/llcamera.h:36`, user setting `CameraAngle`), clamped by aspect (`llcamera.cpp:80-95`). `mCosHalfCameraFOV`, `mPixelMeterRatio` derived in `updateCameraLocation` (`llviewercamera.cpp:98-160`, which also keeps the eye 0.2 m away from the water plane).
- Near/far: `MIN_NEAR_PLANE = 0.1`, `DEFAULT_NEAR_PLANE = 0.25`, `MAX_FAR_CLIP = 512`, `DEFAULT_FAR_PLANE = 64` (`llcamera.h:38-47`). Each frame `display_update_camera` (`newview/llviewerdisplay.cpp:220-262`) sets `far = gAgentCamera.mDrawDistance` (`RenderFarClip`; halved in appearance mode, 64 m for probe snapshots) and `LLWorld::setLandFarClip`; `setNear(MIN_NEAR_PLANE)` at `:783`. The world pass is rendered with `MAX_FAR_CLIP` as the GL far plane (`setPerspective` default, `:353-356`) while culling uses the draw distance; water reflections/refractions clip with `waterPlane` (`waterClip`, `deferredUtil.glsl`), and the camera-under-water state switches fog density and the water-height uniform.
- LOD, impostor and visibility distances scale with `RenderVolumeLODFactor` etc.; avatars render within `clamp(far, 16, 256)` (`llviewerdisplay.cpp:256`).
- HUD attachments (`render_hud_attachments`, `llviewerdisplay.cpp:1400-1510`; `get_hud_matrices`, `:1541-1584`): drawn after the world with an orthographic projection `ortho(-0.5*aspect, 0.5*aspect, -0.5, 0.5, 0, hud_depth)` with `proj[2][2] = -0.01`, model = `OGL_TO_CFR * T(-bbox.centerX + depth/2, 0, 0) * S(HUD zoom)`; the HUD camera sits at `(-1,0,0)` looking +X. HUD objects are attached to the HUD attachment points (`getHUDBBox`, `newview/llvoavatar.cpp:10585-10620`); HUD faces are forced FULLBRIGHT (`llvovolume.cpp:6240-6243`), always LOD 3, rendered in sRGB space (`IS_HUD` shader variants), not affected by atmosphere.

## Draw-pass selection summary (what a face needs to replicate the look)

`LLVolumeGeometryManager::rebuildGeom` classifies faces (`llvovolume.cpp:6240-6400`) into simple / alpha / PBR / norm-spec / norm / spec / bump / fullbright buckets (which decides the vertex mask), and `genDrawInfo` (`:6950-7260`) registers passes: GLTF material -> `PASS_GLTF_PBR` / `PASS_GLTF_PBR_ALPHA_MASK` / `PASS_ALPHA`; legacy material -> table indexed by `getShaderMask` (`PASS_MATERIAL*`, `PASS_SPECMAP*`, `PASS_NORMMAP*`, `PASS_NORMSPEC*`, with BLEND variants routed to `PASS_ALPHA`), fullbright materials -> `PASS_FULLBRIGHT(_ALPHA_MASK)` unless env intensity/shiny, legacy bump without normal map -> `PASS_BUMP`; no material -> `PASS_ALPHA_INVISIBLE` (alpha 0), `PASS_(FULLBRIGHT_)ALPHA_MASK` when `canRenderAsMask` (`llface.cpp:1225-1260`: alpha-mask-capable texture, colour alpha 1, glow 0, not rigged, not HUD, auto-mask settings), `PASS_ALPHA`, `PASS_(FULLBRIGHT_)SHINY`, `PASS_INVISIBLE`/`PASS_INVISI_SHINY` for GL_ALPHA "invisiprim" textures, `PASS_BUMP`/`PASS_POST_BUMP`, `PASS_SIMPLE`/`PASS_FULLBRIGHT`; glow adds `PASS_GLOW`/`PASS_GLTF_GLOW`.
